## 字体与兼容性

- 可编辑版：全部文本、主题和备注的字体声明统一为 **黑体（SimHei）**。化学式、参数和单位使用PowerPoint原生上下标，移除了旧版容易缺字的Unicode上下标字符。本机需有SimHei字体才能严格按该字体显示。
- 防乱码放映版：同样26页，页面已转为1920级分辨率图像，不依赖本机字体，可放映，文字不能单独编辑；逐页备注仍保留。
- PDF：使用云端可用的Noto Sans CJK SC黑体类字体渲染并嵌入字体。云端没有Windows SimHei，因此未声称PDF中嵌入了SimHei。
- 引用的论文图表保留原始图内字体与数据。封面的汇报人、日期留空，供使用者填写。

## 内容安排

1-4页：研究背景、汇报逻辑及参数定义。

5-13页：文献一的截面构建、弹性、振动、附着、能量损失、群参数结果及局限。

14-21页：文献二的电极结构、流体方程、数值验证、比较工况、三档背景场结果及重复流注。

22-26页：两篇对比、测量设计启发、后续研究闭环、总结及完整参考文献。
